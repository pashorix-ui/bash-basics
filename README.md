# Bash Basics

A beginner project for practicing Bash scripting on Fedora Linux.

## hello.sh
Creates a greeting using a Bash variable.
Demonstrates variables, comments, and echo.

## greet.sh
Greets a user using a command-line argument.
Demonstrates argument handling and exit codes.

## sysinfo.sh
Displays basic information about the Linux system.
Uses date, hostname, whoami, uptime, df, and free.

## list-scripts.sh
Lists all Bash scripts in the current directory.
Demonstrates a Bash for loop and filename matching.
